CUSTOMCARZ AUTO CARE — CORRECTED GITHUB PAGES PACKAGE

Use this package to replace the files in the ROOT of the GitHub Pages repository.
Keep the repository branch on: main

IMPORTANT:
- Extract the ZIP before uploading.
- Upload/replace the CONTENTS of the extracted folder, not the ZIP itself.
- Keep the existing assets/ and assets/products/ files.
- index.html is the customer website.
- admin.html is the owner admin.

CUSTOMER WEBSITE FIXES:
- Removed the client-facing Admin tab/link.

- products.json and site.json are loaded from the same GitHub Pages root.

ADMIN:

https://customcarzautocare.co.ke/admin.html

GITHUB TOKEN:
Use a fine-grained GitHub Personal Access Token that has access to this repository with:
Contents: Read and write

If Connect & Load reports an error, read the exact red error message; it will now show the GitHub response instead of appearing to do nothing.

AFTER UPLOADING:
1. Wait for GitHub Pages deployment to finish.
2. Open the customer website in a private/incognito tab or hard-refresh.
3. Open /admin.html separately for owner editing.

SECURITY NOTE:
Do not put the GitHub token into any repository file. The admin only uses the token from the browser input/session.
