CUSTOMCARZ FINAL UPLOAD GUIDE

1. Extract this ZIP.
2. Upload the CONTENTS of this folder to the ROOT of the GitHub repository:
   customcarzautocare / Customcarzautocare.co.ke-
3. Keep the existing repository CNAME and replace the updated files when GitHub asks.
4. The repository root should contain:
   index.html
   admin.html
   products.json
   site.json
   CNAME
   .nojekyll
   assets/
   *.jpg site images
5. Do NOT upload the ZIP as a single file.
6. After GitHub Pages deploys, open the customer website and test:
   - category buttons
   - product DETAILS modal
   - WhatsApp and Call
   - floating navigation
   - floating social/map buttons
   - product search and filters
   - gallery
7. Admin is at /admin.html. It can edit products, descriptions, categories, text overrides, gallery/site photos, business settings, links and review cards.

SOCIAL LINKS NOTE:
Instagram is set to the known Customcarz account. Public web search did not reliably verify Facebook, X/Twitter or TikTok accounts for this business, so those fields remain editable in Admin rather than inventing an account URL.
