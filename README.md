# Customcarz Auto Care

Customer website and browser-based GitHub admin for Customcarz Auto Care / Customcarz Imports.

- Customer: `index.html`
- Admin: `admin.html`
- Site content/settings: `site.json`
- Product catalogue: `products.json`
- Site/gallery images: `assets/site/`
- Product images: `assets/products/`

The public site is designed for GitHub Pages and loads the JSON files at runtime with cache-busting requests so catalogue and content updates appear after deployment.
